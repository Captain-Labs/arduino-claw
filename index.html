          AI Setup Guide & Keys
        

        
      

      
      

        
        
        

          

            Cerebras (Free with limits)
            
          

          

            

              
1. Get API Key: Go to the Cerebras Console , register/sign in, navigate to API Keys, and generate a new key.

              
2. Configuration: Go to settings in this app, set provider to Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: https://api.cerebras.ai/v1
    • 
                  
  • API Key: Paste your Cerebras Key
    • 
                  
  • Model Name: llama-3.3-70b, llama3.1-8b, llama3.1-70b, llama-4-maverick-17b-128e-instruct, gemma-4-31b, zai-glm-4.7, gpt-oss-120b, etc.
    • 
                

              

            

          

        


        
        

          

            Groq (Free with limits)
            
          

          

            

              
1. Get API Key: Go to the Groq Console , navigate to API Keys, and generate a new key.

              
2. Configuration: Open settings, select provider Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: https://api.groq.com/openai/v1
    • 
                  
  • API Key: Paste your Groq Key
    • 
                  
  • Model Name: llama-3.3-70b-versatile, llama-3.1-8b-instant, gemma2-9b-it, mixtral-8x7b-32768, etc.
    • 
                

              

            

          

        


        
        

          

            SambaNova (Free with limits)
            
          

          

            

              
1. Get API Key: Go to SambaNova Cloud , register, and copy your API key.

              
2. Configuration: Set provider to Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: https://api.sambanova.ai/v1
    • 
                  
  • API Key: Paste your SambaNova Key
    • 
                  
  • Model Name: Meta-Llama-3.3-70B-Instruct, Meta-Llama-3.1-8B-Instruct, Meta-Llama-3.1-70B-Instruct, DeepSeek-R1, DeepSeek-V3, etc.
    • 
                

              

            

          

        


        
        

          

            OpenRouter (Free)
            
          

          

            

              
1. Get API Key: Visit OpenRouter.ai , create an account, go to Keys, and click Create Key.

              
2. Configuration: Set provider to Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: https://openrouter.ai/api/v1
    • 
                  
  • API Key: Paste your OpenRouter Key
    • 
                  
  • Model Name: meta-llama/llama-3.3-70b-instruct, meta-llama/llama-3.1-8b-instruct:free, google/gemini-2.0-flash-exp:free, deepseek/deepseek-chat, deepseek/deepseek-r1, etc.
    • 
                

              

            

          

        


        
        

          

            DeepSeek
            
          

          

            

              
1. Get API Key: Go to the DeepSeek Console , click API Keys, and create a new key.

              
2. Configuration: Set provider to Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: https://api.deepseek.com/v1
    • 
                  
  • API Key: Paste your DeepSeek Key
    • 
                  
  • Model Name: deepseek-chat, deepseek-reasoner, etc.
    • 
                

              

            

          

        


        
        

          

            Ollama (Local)
            
          

          

            

              
1. Setup Local Server: Download and install Ollama . Run a model in your terminal, e.g. ollama run llama3.

              
2. Configuration: Choose Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: http://localhost:11434/v1
    • 
                  
  • API Key: Leave empty
    • 
                  
  • Model Name: llama3, llama3.1, llama3.3, gemma2, qwen2.5-coder, deepseek-r1, etc.
    • 
                

              

            

          

        


        
        

          

            Gemini
            
          

          

            

              
1. Get API Key: Log in to Google AI Studio , click Get API Key and generate a new key.

              
2. Configuration: Open settings, set provider to Gemini.

              
3. Fields to Paste:
                
    
                  
  • Gemini API Key: Paste your key here
    • 
                  
  • Model Name: gemini-2.0-flash (default), gemini-2.0-flash-lite, gemini-1.5-flash, gemini-1.5-pro, gemini-2.0-pro-exp-02-05, etc.
    • 
                

              

            

          

        


        
        

          

            Claude
            
          

          

            

              
1. Get API Key: Register/login at the Anthropic Console , click API Keys, and generate a new key.

              
2. Configuration: Set provider to Claude.

              
3. Fields to Paste:
                
    
                  
  • Claude API Key: Paste your key here
    • 
                  
  • Model Name: claude-3-5-sonnet-latest (default), claude-3-5-haiku-latest, claude-3-opus-latest, claude-sonnet-4-20250514, etc.
    • 
                

              

            

          

        


        
        

          

            Custom URL
            
          

          

            

              
1. Details: For any provider running an OpenAI-compatible endpoint.

              
2. Setup: Choose Custom URL (OpenAI-compatible).

              
3. Fields to Paste:
                
    
                  
  • API Base URL: Base endpoint (e.g. https://api.yourprovider.com/v1)
    • 
                  
  • API Key: Your API Key
    • 
                  
  • Model Name: Desired model identifier string, etc.
    •
