Capabilities

Everything You Need to Build Faster

Arduino Claw merges conversational AI reasoning with native hardware compilation into a single, cohesive desktop application.

AI Pin Selection & Wiring Guide

Never guess pinouts or search datasheets again. If your command doesn't specify component pins, Arduino Claw prompts with "Let AI Decide Pins" or "Enter Pins Manually", generating an automatic Pin Connection Guide table mapping component pins, voltages, and microcontroller pins with zero ambiguity.

Prompt to Firmware in Seconds

Explain your electronics logic in simple conversational language. The AI understands sensor pinouts, I2C addresses, interrupts, and timings, generating bug-free Arduino C++ sketches with full explanations.

Zero-Config Embedded Compiler

No command-line wrestling, no separate Python server launches, and zero manual installations. The embedded native Arduino CLI compiler starts silently in the background on launch.

Direct USB Serial Flashing

Flash compiled .hex binaries directly onto your board via high-speed STK500v1 serial protocols with a single click—no external programmer hardware required.

Native Port Selection Modal

The built-in device scanner identifies connected USB boards, serial port names, and hardware VID:PIDs with real-time refresh and safe auto-connect.

Use Any AI Model of Your Choice

Complete model freedom without vendor lock-in. Connect your API key for Google Gemini, Groq, Cerebras, OpenRouter, or run 100% private and offline using local Ollama or LM Studio. You can use any model you prefer.

Real-Time Serial Monitor

Live bidirectional terminal with auto-scrolling telemetry, multi-speed baud rate control (300 to 115200), and auto-upload telemetry verification.

Workflow

From Idea to Hardware in 3 Simple Steps

Say goodbye to syntax errors, missing include files, and endless forum troubleshooting.

01

Connect Your Arduino Uno R3

Plug your Arduino Uno R3 board into USB. Click Connect in the navbar and select your port from the device list.

02

Describe Your Idea

Type what you want to build in plain English. The AI drafts the schematic guidance, chooses pins, and writes the sketch.

03

Flash & Run

Click Flash USB. The embedded engine compiles the binary and writes it straight to your microcontroller memory.

Common Questions

Frequently Asked Questions

Everything you need to know about setting up and programming with Arduino Claw.

Can I use Arduino Claw completely offline?

Yes! By pointing the AI Settings to a local Ollama or LM Studio instance, you can prompt, generate code, compile, and flash entirely offline without sending any code or prompts over the internet.

Do I need to install the official Arduino IDE first?

No. Arduino Claw bundles its own internal compiler runtime, toolchains, and USB communication bridges. You do not need the Arduino IDE installed on your computer.

How does in-app USB flashing work?

Arduino Claw communicates over your computer's USB serial controller using native STK500v1 serial flashing routines. When you click Flash, it opens the selected serial port, triggers the microcontroller DTR auto-reset, and streams the compiled hex payload directly into flash memory.

Which AI providers and models can I use?

Arduino Claw is completely model-agnostic. You can connect any model from any provider—including Google Gemini, Groq, Cerebras, SambaNova, OpenRouter—or run any local offline model with Ollama or LM Studio. You have full freedom to use any model of your choice.

Is Arduino Claw open source?

Yes. Arduino Claw is 100% open source and licensed under the permissive MIT License. You can inspect the source code, fork the project, and contribute on GitHub.
